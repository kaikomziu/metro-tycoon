# METRO TYCOON

初期資金 ¥100 で駅を買い、駅と駅を路線でつなぎ、走る電車で稼ぐ Mini Metro 風の鉄道経営ゲーム。

**あそぶ:** https://kaikomziu.github.io/metro-tycoon/

## ルール
- 駅をタップ → 別の駅をタップで路線を敷設。終点をもう一度タップ、または「完了」で確定。
- 2駅以上つなぐと列車が自動運行。乗客を運ぶたびに運賃が入り、運行するだけでも少額の収入。
- 長い区間ほど運賃アップ。点線の丸は購入できる駅。
- 乗客が溢れた駅を放置すると（赤いリングが一周で）ゲームオーバー。
- アップグレード: 運賃改定 / 車両大型化 / 加速性能 / 増発 / 沿線開発 / 新規開業。
- 進行はブラウザに自動保存。

## 技術
- 依存なしのバニラ JS + Canvas、単一ページ。
- `js/game.js` がゲーム本体、`js/version.js` が更新履歴。

更新履歴は `js/version.js` を参照。
